# Scripts

course3: Simulates single-pulse propagation through fiber using the Split-Step Fourier Method (SSFM). 
* **Effects simulated:** Attenuation, Chromatic Dispersion (GVD), Kerr Nonlinearity (SPM).
* Also calculates the adaptive step size for the SSFM loop based on nonlinear phase shift.

final: Full coherent QPSK transmission system simulator.
* **Effects simulated:** Electrical pulse shaping, IQ Mach-Zehnder Modulation, Fiber Channel (Dispersion + Attenuation), Additive White Gaussian Noise (AWGN), Coherent Homodyne Detection, and Threshold Decoding.
